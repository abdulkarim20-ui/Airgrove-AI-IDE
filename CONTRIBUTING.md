# Contributing to AirGrove

First off, thank you for considering contributing to AirGrove! It's people like you who make AirGrove such a great tool.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. Please report any unacceptable behavior.

## How Can I Contribute?

### Reporting Bugs
* **Check the FAQ** to see if your issue is already addressed.
* **Search existing issues** to see if the bug has already been reported.
* **Provide details**: Include your OS, version, and a clear set of steps to reproduce the error.

### Suggesting Enhancements
* **Explain why** this enhancement would be useful to most AirGrove users.
* **Describe the functionality** you'd like to see.

### Pull Requests
1. **Fork the repo** and create your branch from `main`.
2. **Install dependencies** with `npm install`.
3. **Write clean code** following the existing style of the repository.
4. **Test your changes** thoroughly.
5. **Update documentation** if your changes add or modify functionality.
6. **Submit the PR** with a clear description of the problem and solution.

## Style Guidelines
* Use 2 spaces for indentation.
* Follow standard JavaScript/ESLint best practices.
* Ensure all new components are responsive and align with the existing "Premium Dark Mode" aesthetic.
